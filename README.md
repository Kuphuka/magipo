# Magipo Holdings website

A responsive, static website for MAGIPO HOLDINGS (PTY) LTD.

## Run locally

Open `index.html` in a web browser. The site uses Google Fonts and Unsplash-hosted
photography, so an internet connection is needed for those assets.

## Files

- `index.html` — page content and inline SVG wordmark
- `styles.css` — responsive layout, styling, and motion
- `script.js` — mobile navigation and scroll reveals
- `magipo.jpeg` — original supplied logo reference
